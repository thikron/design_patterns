# Design Patterns anhand von Beispielen in TypeScript
In diesem Repository werden verschiedene Design Patterns anhand von Beispielen in Java implementiert. Jedes Design

## Initial:
Node Packages installieren:
```shell
npm install
```

## Ausführen:
```shell
npm run <pattern-category>:<pattern-name>
```

pattern-category: creational, structural, behavioral
pattern-name: factory_method, singleton, composite, etc.

Bespiel:
```shell
npm run creational:factoryMethod
```
